# github-utils

`github-utils` is a Claude Code plugin that bundles GitHub-focused skills:

- `gh-cli`
- `pr-review`
- `new-issue`
- `changelog`

## Skills

- `/github-utils:gh-cli`
- `/github-utils:pr-review`
- `/github-utils:new-issue`
- `/github-utils:changelog`

## Notes

The skill contents were initially copied from the local standalone skills directory and kept unchanged so they can be reviewed and refined later.
